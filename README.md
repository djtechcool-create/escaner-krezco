# Escáner Krezco

Aplicación web instalable para leer códigos de barras desde la cámara o desde una imagen cargada.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `escaner-krezco`.
2. Sube todos los archivos de esta carpeta, sin cambiar su estructura.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
5. Guarda. GitHub mostrará la dirección pública de la aplicación en unos minutos.

Abre esa dirección una primera vez con conexión a internet. En Android, Chrome mostrará la opción **Instalar app**; también puedes usar el menú de Chrome y seleccionar **Instalar aplicación**. En iPhone, abre la dirección con Safari, pulsa **Compartir** y selecciona **Añadir a pantalla de inicio**.

La cámara funciona únicamente desde una dirección segura (`https://`), como GitHub Pages. Las imágenes aceptadas son JPG, PNG, WEBP, GIF y BMP.

## Uso

- **Usar cámara:** apunta el recuadro al código. Los códigos repetidos no se agregan otra vez.
- **Subir imagen:** marca con el cursor o dedo la parte que contiene el código y pulsa **Leer selección**. También puedes analizar la imagen completa.
- **Resultados:** copia uno o todos los resultados desde PC. En móvil, el botón de WhatsApp abre un mensaje nuevo con los códigos encontrados.
